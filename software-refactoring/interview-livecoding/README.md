# Live coding interview

## Getting started

### Prerequisites

To work on the application, everything you need is a JDK. You may use version 11
or above.

### Building the project

The project is built using Gradle. This repository provides a Gradle wrapper so that
you don't have to install it on your own machine. Running the `gradlew` script will
download the appropriate version of Gradle in a transparent manner.

On Linux or macOS:

```shell
$ ./gradlew build
```

On Windows:

```shell
gradlew.bat build
```
